# Sarkin Wanka — Gestion d'atelier (v4.1)

Application de gestion d'un atelier de couture (commandes, clients, tailleurs, stock, finances, reçus) :
une seule page `index.html`, emballée en APK Android avec Capacitor. Les données restent sur l'appareil.

- **Guide complet : `GUIDE.md`** — commandes à copier-coller : **`COMMANDES.txt`**
- Publier une mise à jour : `PUBLIER.bat` (aucune recompilation pour les utilisateurs)
- Envoyer sur GitHub : `GIT_ENVOYER.bat`
- Clé de signature : `android/sarkin-wanka.keystore` + `android/keystore.properties` — **jamais dans Git** (voir `.gitignore`)
